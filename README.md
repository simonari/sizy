# sizy

Интерактивный обзор размеров файлов и папок в терминале — TUI на
[Textual](https://textual.textualize.io/). Работает в macOS, Linux и Windows.

## Установка

```bash
uv sync
```

## Запуск

```bash
uv run sizy            # текущая директория
uv run sizy ~/Projects # конкретная директория
python -m sizy PATH    # то же самое
```

## Клавиши

| Клавиша     | Действие                              |
| ----------- | ------------------------------------- |
| `Enter`     | войти в выбранную папку               |
| `Backspace` | подняться на уровень выше             |
| `s`         | сортировка: по размеру / по имени     |
| `r`         | пересканировать                       |
| `q`         | выход                                 |

`↑`/`↓`, `PgUp`/`PgDn`, `Home`/`End` — перемещение по списку,
колесо мыши работает.

## Что считается

- Размер — «apparent size» (`st_size`), то есть сумма размеров файлов;
  для директорий — сумма всех потомков.
- Символические ссылки не разворачиваются: учитывается размер самой ссылки.
- Жёсткие ссылки на одном устройстве учитываются один раз
  (по паре `st_dev` + `st_ino`), чтобы не завышать итог.
- Сканирование не переходит границы файловой системы (например, в
  смонтированные диски внутри домашней папки).
- Файлы и папки без прав доступа пропускаются; их количество видно в
  строке статуса.

Сканирование идёт в фоновом потоке, интерфейс при этом не блокируется:
прогресс и текущая обрабатываемая папка отображаются в статусной строке.

## Готовые бинарники

Standalone-сборки не требуют установленного Python. GitHub Actions собирает
их на трёх ОС и прикрепляет к релизу при пуше тега:

```bash
git tag v0.1.0
git push origin v0.1.0
```

Артефакты (`sizy-macos-arm64`, `sizy-linux-x86_64`,
`sizy-windows-x86_64.exe`) также доступны на вкладке Actions.

Локальная сборка под текущую ОС — PyInstaller не умеет кросс-компиляцию:

```bash
uv sync
uv run python scripts/build.py
```

Результат: `dist/sizy-<os>-<arch>` (на Windows — `.exe`), около 16 MiB.
Linux-бинарник собирается на Ubuntu 22.04 ради совместимости по glibc;
macOS-сборка — Apple Silicon (Intel нужно собрать локально).

Если macOS блокирует скачанный файл:

```bash
xattr -d com.apple.quarantine ./sizy-macos-arm64
```

## Тесты

```bash
uv run pytest
```

Покрыто: агрегация размеров, жёсткие ссылки, симлинки, ошибки доступа,
отмена сканирования, прогресс, навигация и сортировка в TUI, аргументы CLI.

## Структура

```
src/sizy/
├── __init__.py   # CLI и точка входа
├── __main__.py   # python -m sizy
├── scanner.py    # обход ФС, агрегация размеров, дедупликация хардлинков
└── app.py        # Textual-приложение: таблица, навигация, прогресс

tests/
├── test_scanner.py  # сканер: размеры, ссылки, ошибки, отмена
├── test_app.py      # TUI: навигация, сортировка, пересканирование
└── test_cli.py      # аргументы командной строки

scripts/
├── entrypoint.py    # точка входа для PyInstaller
└── build.py         # сборка бинарника под текущую ОС

.github/workflows/build.yml  # тесты, сборка под 3 ОС, релиз по тегу
```
